3. Scroll to **Emoji Skin Tone**.
4. Choose your preferred tone.
5. Save changes.

# 🔫 Quickdraw

<div align="center">

| Difficulty | Time | Solo | Cost |
|:----------:|:---:|:---:|:---:|
| 🟢 Easy | 2 Minutes | ✅ Yes | Free |

</div>

## 🎯 Requirement

Close an Issue or Pull Request within **5 minutes** after creating it.

---

## ✅ Step-by-Step

### Method 1 (Easiest)

1. Open one of your repositories.

2. Click **Issues**.

3. Click **New Issue**.

4. Enter any title.

Example:

```
Test Issue
```

5. Click **Submit new issue**.

6. Immediately click

```
Close Issue
```

within **5 minutes**.

That's it!

---

### Method 2

Instead of an Issue,

Create a Pull Request.

Merge or Close it within 5 minutes.

---

## 💡 Tips

✅ Use your own repository.

✅ No collaborators required.

✅ Public repository recommended.

---

## ❌ Common Mistakes

❌ Waiting longer than 5 minutes.

❌ Closing someone else's issue.

❌ Repository permissions preventing closure.

---

## 🎉 Badge Earned!

GitHub usually awards it within a few minutes.

Sometimes it may take 24 hours.

# 🤪 YOLO

<div align="center">

| Difficulty | Time | Solo | Cost |
|:----------:|:----:|:----:|:----:|
| 🟡 Medium | 15–20 Minutes | ✅ Yes* | Free |

</div>

> *Solo works only if your repository does not require code reviews.*

---

## 🎯 Requirement

Merge a Pull Request **without any code review**.

---

## ✅ Method 1 (Recommended)

1. Create a repository.
2. Create a new branch.

```bash
git checkout -b feature-yolo
```

3. Make any change.

```bash
echo "YOLO Badge" >> README.md
```

4. Commit it.

```bash
git add .
git commit -m "YOLO Badge"
```

5. Push the branch.

```bash
git push origin feature-yolo
```

6. Open a Pull Request.

7. **Do NOT request a review.**

8. Merge immediately.

🎉 Badge unlocked.

---

## Method 2

Use another GitHub account.

Open a PR.

Merge it without requesting a review.

---

## ❌ Common Mistakes

❌ Requesting code review.

❌ Repository has branch protection enabled.

❌ PR closed instead of merged.

---

## 💡 Pro Tips

- Disable "Require Reviews" in Branch Protection.
- Small PRs are easier.
- Public repositories are recommended.

# 🚨 Hidden Rules & Things GitHub Doesn't Tell You

Many achievements have hidden conditions. Keep these in mind to avoid frustration.

## 🔒 Public vs Private Repositories

- Most achievements count public activity by default.
- Private activity can count if **"Include private contributions on my profile"** is enabled.

---

## 🔀 Pull Requests Must Be Merged

Creating a Pull Request is **not enough**.

❌ Closed PR → Doesn't count

✅ Merged PR → Counts

---

## ⭐ Starstruck

- Repository must be **personally owned**.
- Organization repositories don't count.
- Buying stars or using fake accounts violates GitHub's rules.

---

## 🤪 YOLO

- Branch protection requiring reviews will prevent earning this badge.
- Merge the PR without requesting or approving a review.

---

## 🧠 Galaxy Brain

GitHub Community Discussions no longer award this badge.

Instead, earn accepted answers in **repository Discussions**.

---

## 👥 Pair Extraordinaire

The commit message **must** contain:

```text
Co-authored-by: Name <email@example.com>
```

GitHub won't recognize any other format.

---

# 🔧 Troubleshooting

## Badge isn't appearing

Try these steps:

- Refresh your profile.
- Wait up to **48 hours**.
- Check if the repository is public.
- Confirm the activity meets the badge requirements.

---

## Pull Shark not awarded

Check:

- PR was merged.
- PR wasn't just closed.
- Repository isn't a fork.

---

## YOLO not awarded

Verify:

- No code review was requested.
- Branch protection didn't require reviews.

---

## Galaxy Brain not awarded

Possible reasons:

- Discussion wasn't in a repository.
- Your answer wasn't accepted.
- You answered in GitHub Community instead of repository Discussions.

---

## Starstruck not awarded

Check:

- Repository is owned by you.
- Repository actually reached the required star count.
- Stars are from real users.

# ❓ Frequently Asked Questions

### Can achievements disappear?

No.

Once earned, achievements stay on your profile unless GitHub changes its system.

---

### Can I hide achievements?

Yes.

Go to:

```
Settings → Public Profile → Achievements
```

---

### Do private repositories count?

Only if private contributions are enabled.

---

### Can organization repositories earn Starstruck?

No.

Only repositories you personally own count.

---

### Can I earn multiple tiers at once?

Yes.

If you skip directly to a higher milestone, GitHub awards the highest tier you've reached.

---

### Can I lose a badge?

No.

Achievements are permanent.

---

### How long do badges take?

Usually a few minutes.

Sometimes up to **48 hours**.

---

### Do archived repositories count?

Existing achievements remain.

Future progress may not.
